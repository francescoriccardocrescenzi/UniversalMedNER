\begin{frame}{Motivation}
  \begin{itemize}
    \item Biomedical named-entity recognition (NER) underpins clinical text mining, literature curation, and downstream information extraction.
    \item General-purpose LLMs perform poorly out-of-the-box on fine-grained biomedical entity typing.
    \item Goal: adapt \textbf{MedGemma}, a biomedical instruction-tuned model, into a strong NER extractor via fine-tuning.
    \item The model is given the raw text plus a \emph{candidate list of entity types} and must extract spans for each type.
  \end{itemize}
\end{frame}
